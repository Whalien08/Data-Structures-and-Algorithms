# Data Structures and Algorithms

This repository contains my C programming lab implementations for various Data Structures and Algorithms completed during my third semester of undergraduate studies.

## Table of Contents

## About
This collection includes fundamental implementations of sorting techniques, queue management, linked lists, and expression parsing. These projects helped me understand memory management, pointer arithmetic, and algorithmic complexity in C.

## Programs Included

| File | Description |
| :--- | :--- |
| `bubble.c` | Implementation of Bubble Sort algorithm. |
| `insertion.c` | Implementation of Insertion Sort algorithm. |
| `merge.c` | Implementation of Merge Sort algorithm. |
| `heap.c` | Implementation of Heap Sort algorithm. |
| `circular.c` | Circular Queue implementation with enqueue/dequeue operations. |
| `linked.c` | Singly linked list with various insertion and deletion operations. |
| `palliLL.c` | Palindrome checking using a doubly linked list. |
| `polyA.c` | Polynomial addition using structure arrays. |
| `infix2post.c` | Infix to Postfix conversion and evaluation. |
| `infix2pre.c` | Infix to Prefix conversion and evaluation. |
| `queueLL.c` |  Implemntation of Queue using Linked List |
| `quick.c` | Qucik sort algorithm |
| `revers.c` | Reverse the elements with stack |
| `selection.c` | Selection Sort Algorithm |
| `stackLL.c` | Implementation Stack using Linked List
